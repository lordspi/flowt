## 📐 Image Specifications

### Recommended Image Sizes:
- **Carousel images**: 600x600px (1:1 ratio)
- **Thumbnail images**: 400x300px (4:3 ratio)
- **Main showcase images**: 800x600px (4:3 ratio)
- **Capability examples**: 600x400px (3:2 ratio)
- **Before/After examples**: 600x400px (3:2 ratio)
- **Ad format images**: 400x300px (4:3 ratio)

### Image Quality:
- Use high-quality JPG or PNG files
- Ensure good lighting and professional appearance
- Keep file sizes under 500KB for faster loading
- Use consistent style and branding across all images

## 🎨 Content Guidelines

### For Commercial Photography Images:
- Show clean, professional product shots
- Include lifestyle contexts where relevant
- Demonstrate studio-quality lighting
- Highlight product details and features

### For Brand Voice Images:
- Maintain consistent visual style
- Show brand elements and identity
- Include multi-platform applications
- Demonstrate brand guidelines in action

### For Capability Examples:
- Show clear before/after transformations
- Highlight specific features being demonstrated
- Use diverse product types and styles
- Ensure the improvement is clearly visible

## 📋 Upload Checklist

Before uploading, ensure:
- [ ] All images have the exact filenames specified
- [ ] Images are placed in the correct folders
- [ ] File sizes are optimized for web
- [ ] Images maintain professional quality
- [ ] Consistent branding across all visuals
- [ ] No watermarks or placeholder text

## 🚀 After Upload

Once all images are uploaded:
1. Test the website to ensure all images load correctly
2. Check for any broken image links
3. Verify image alignment and appearance
4. Test responsive behavior on different screen sizes

## 💡 Pro Tips

- Use a consistent color palette across all images
- Ensure products are well-lit and clearly visible
- Include diverse product types to showcase versatility
- Keep backgrounds clean and professional
- Test images on both light and dark website themes
